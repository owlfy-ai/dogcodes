# 桌面终端执行生命周期改造

日期：2026-10-16。对应 DT-08，以及终端启动的 DT-09 可靠性。后台服务和桌面终端/项目进程接入已实现；项目运行目录亦已迁入服务；其他窗口依赖、操作可靠性补齐和三平台实机验收仍未完成，不是发布验收通过。

## 已实现的服务边界

`apps/desktop/src-tauri/src/terminal_host/` 管理 PTY，与 Tauri 窗口和 Channel 无关，由 daemon 的 `ServiceControl` 持有。桌面 `terminal.rs` 已替换为薄适配层，旧的窗口持有 PTY 实现、窗口销毁杀进程和 Channel 失败杀进程代码已移除。项目运行也使用同一后台终端资源。

- 2026-10-17：终端信息带当前 PTY 尺寸（`cols`/`rows`），多个客户端共享同一尺寸，最近一次成功调整生效；屏幕快照未实现，重新附着只重放输出尾部。
- 提供启动、列出、查询、读取输出、输入、调整尺寸、停止七项本机 RPC；沿用 daemon 的连接认证。新启动在后台校验项目目录范围与可选会话归属。
- 客户端生成稳定 UUID 作为逻辑启动身份。同 ID、同完整载荷返回原资源；同 ID、不同载荷拒绝。后台先原子持久化启动意图，再启动进程；启动回执丢失不自动发起新操作。
- 每个后台实例有独立 epoch。服务重开时，未结束的旧记录标为 Unknown，不自动重新执行，也不保存/使用旧 PID 去停止进程。已结束记录可以查询；保留记录用于防止启动重放。
- 输出读取独立于视图。每终端最多缓存 1 MiB 输出，单次返回最多 64 KiB，按字节游标续传；缓存淘汰或重启后输出不可用时明确返回 gap。完成资源最多保留最近 32 份输出，元数据保留；同时活动的资源上限为 64。
- 输入不自动重放。输入写锁与进程控制锁分开，PTY 输入缓冲阻塞时仍可停止。回收子进程与停止使用同一把进程锁，避免回收后进程号复用的竞态；自然退出不再按旧 PID 清理。
- 服务有活动终端时拒绝空闲退役。关闭读取连接不会停止进程；明确停止请求才回收对应进程。退出状态由进程回收结果决定，停止请求成功不直接伪造 Exited。
- 启动记录写在应用私有数据目录的 `terminal-operations`，不是源码树或发布配置。损坏记录不自动清空，拒绝新增启动并给出核实提示。

## 桌面接入与验证补充

- `terminalClient.ts` 用长轮询读取输出，每连接保留独立字节游标。detach 仅丢弃未完成读取及停止后续轮询，不发停止命令；已结束进程的缓存输出仍会读完。断线显示状态待核实，缺口有明确文案，Unknown 不伪装为完成。
- `TerminalDock` 首次打开先列出后台资源，读取失败不自动创建默认 shell。隐藏标签/卸载仅断开视图，恢复入口连接原资源；“停止终端”单独发送停止请求。未知启动回执先查询原操作，必要时仅在用户重试时重发同 ID/尺寸，输入字节从不重放。
- 项目运行使用稳定启动 ID，窗口重开查询对应会话的已有进程；隐藏输出保留执行记录，可从运行项或恢复输出入口重新打开，不重复运行。启动回复到达前请求停止时，收到资源后继续停止它；未核实状态不触发完成回调。
- Tauri 新增 list/get/read 三个查询入口；主窗口可操作本地终端，独立审查窗口只能访问其对应会话的项目进程。此处保留桌面入口限制，后台资源仍不归窗口所有。
- 后续工作块已将项目运行目录的分析、编辑和 generation 校验迁入后台 `ProjectRunHost`，见[运行配置服务记录](desktop-project-run-service-2026-10-16.md)。分析/编辑的持久操作身份已补，仍需其他可靠性边界和实机验收，DT-08/10 不能因此关闭。
