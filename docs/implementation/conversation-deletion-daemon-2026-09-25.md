## 通过项

| 检查 | 结果 |
| --- | --- |
| 普通、置顶、归档会话删除 | 原生桌面分别操作，确认后进入最近删除；取消确认不删除、不切换会话。 |
| 多窗口删除同步 | B/C 同时打开普通会话；B 删除后两边自动移除并切换到同项目其他会话。 |
| 删除保护 | 真实主任务运行/待审批、独立审查排队/运行时两边按钮禁用；直接 RPC 删除分别返回活动任务冲突。终结/取消后允许删除。 |
| 删除最后一个会话 | 六个测试会话全部删除后，两边显示新对话与六项最近删除，无旧会话残留。 |
| 应用与服务重启 | 新服务启动后六个删除状态全部保留。既有首次会话初始化逻辑在没有可见会话时创建一个新的空白会话，ID 不同于被删会话；没有恢复或重发旧消息。 |
| 恢复分组与同步 | B 重启后恢复置顶/归档会话，回到 B 原有分组；恢复历史会话后 C 同步出现并可打开。 |
| 历史内容 | 恢复消息、审查卡片，打开 `sample.txt` 逐轮历史 Diff，显示原修改前后内容。RPC 逐项核对原时间线、8 份原报告、冻结代码来源和 1 条原生会话映射相同。新取消的审查作为新增记录保留，不改写原报告。 |
| 字节及文件保留 | 原 14 份 artifact blob 字节相同；原隔离项目与本次工作目录校验文件未变。 |
| 版本与幂等 | 缺失删除版本、过期恢复版本拒绝；删除命令提交后关闭客户端、不读回包，持同一幂等键重试只产生一次删除。 |
| 查询与订阅 | 删除期间时间线、审查、冻结来源与搜索读取被拒绝；独立订阅收到删除，重连从游标回放仅有一次对应删除事件。 |
| 环境清理 | 所有测试会话恢复；无活动主任务或审查后关闭本次 UI，确认服务继续存在，再空闲退出并停止所属测试子进程。未停止生产服务。 |
