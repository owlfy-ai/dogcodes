# 设备级手动剪贴板（2026-10-22）

手机远程桌面页提供发送文字/图片到电脑、从电脑获取文字/图片四个动作。只响应用户操作，不监听剪贴板变化，不在后台同步。入口不依赖 Agent、屏幕采集权限或视频租约成功；PC 锁屏或权限不可用仍由系统边界拒绝，Agent 会话保持独立。

## 连接和线程

一次传输另开认证连接，先尝试项目已有的 WebRTC DataChannel（直连或 TURN），失败使用自己的 WSS 中继。传输前选定连接，期间不换路、不自动续传/重放，不与业务或画面/键鼠共用消息发送队列。底层链路带宽仍是共享资源，弱网性能不能仅由独立连接或单元测试保证。

PC `remote/clipboard.rs` 具有独立的有界原生线程，负责 OS 剪贴板、PNG 编解码和临时缓冲，避免阻塞 `remote/native.rs` 的键鼠、视频 ACK 和保活。工作入口由 daemon 持有，不依赖桌面窗口。原有 `clipboard_get/set` 也委派给此线程；手机已移除直接发送整块内容的旧快捷 API。

## 协议

能力 `clipboardTransfer { version:1, chunkBytes:32768, maxImageBytes:16777216 }`。`clipboard_transfer` 参数为对象，`operation` 为：

| 操作 | 行为 |
| --- | --- |
| `begin_upload` | 绑定 kind、MIME、大小、SHA-256，创建未写入的缓冲 |
| `append` | 原 offset + base64 小块；相同前缀可重复，间隙/不同内容拒绝 |
| `commit` | 完整且校验一致才写 OS 剪贴板；已写入只返回原回执，不再次覆盖 |
| `status` | 只读核实 staging/applied；不写剪贴板 |
| `begin_download` | 冻结当前剪贴板快照及校验信息，后来复制的内容不改变此传输 |
| `read` | 按 offset 取一小块，手机核对位置、总长和最终 SHA-256 |
| `close` | 释放缓冲；不撤销已完成的复制 |

标识由 PC 生成并绑定物理认证连接。另一连接不能读取、追加、提交或关闭它。手机检查响应身份、方向、类型、大小和摘要；身份错误不会以“成功”吞掉。提交回复丢失或 PC 报超时时，只读核实一次，绝不自动重发 commit；结果仍未知时提示先获取电脑内容核实。新连接不能携带旧缓冲继续写。

这些是短时手动复制，不是 Core 的持久任务命令。重启/断连后不恢复剪贴板写入，也不宣称可撤销已经写入的内容。缓冲仅在 PC 端点内存，不进入服务端共享状态、任务草稿或离线缓存；服务器仍只转发端到端加密数据。

## 手机原生边界

新本地包 `packages/dogcodes_clipboard`：

- iOS：只在用户选择发送时读取 `UIPasteboard`，保留系统粘贴授权；导入图片先检查尺寸并验证 PNG，写入使用 localOnly，图片方向会规范化。参见 [Apple UIPasteboard](https://developer.apple.com/documentation/uikit/uipasteboard)。
- Android：只在前台读取 image content URI；导入后通过范围仅为 `files/clipboard-v1/`、不导出的 FileProvider 供粘贴方读取，保持最近少量文件以支持尚在读取的粘贴方，不申请广泛存储权限。参见 [Android 复制和粘贴](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste)。App 已禁用备份。
- 本地图片写入带唯一标识。页面退出/进入后台可以取消尚在解码的写入，取消在原生主线程确认；已完成的复制不回滚。前台状态会在真正写入前再次检查。PC 上传在提交前、PNG 解码后也检查连接是否仍存活，写入前复查锁屏；已经进入 OS 调用的复制不能回滚。

每张 PNG 上限 16 MiB、约 800 万像素（8×1024×1024），文字上限 1 MiB；PNG 解码前检查尺寸并限制分配。32 KiB 数据块适合手机 RPC 帧。PC 同时至多 4 份缓冲，每连接至多 2 份，空闲 2 分钟或连接关闭释放。这是单项内容和内存限制，不是累计流量阈值，不会因传了若干图片而断开正常连接。

## 验证及剩余验收

- PC：跨连接拒绝、过期/断开/关闭清理、分块顺序和摘要、冻结下载快照、已受理请求重复提交不覆盖新复制、OS 写入失败无受理回执、资源限制；另以阻塞剪贴板后端验证独立远控心跳继续返回。均不读取或更改用户实际剪贴板。
- 手机：文本/图片分块、单帧大小、完整摘要检查、提交前/后丢失及 PC 超时的只读核实、不重放、错误回执、取消/迟到连接清理、P2P/TURN 选择及 WSS 回退；页面测试验证无自动读取、权限拒绝反馈、画面失败仍可使用剪贴板、退出页面取消相同原生写入。
- 隔离 iOS 27 / Android API 37 模拟器真实原生插件：PNG 尺寸/像素往返、损坏图片拒绝且不覆盖原内容、原生取消回执与完成状态一致、文字替换后不返回图片。临时模拟器已清理，用户的原有模拟器未改动。
- 全量计数及构建结果记录于手机 `docs/next-steps.md` 的本轮条目。

仍需真实 Windows/macOS/Linux 桌面与 iPhone/Android 之间分别完成 P2P、TURN、WSS 的跨设备互通、弱网/切网、锁屏/撤权、真实图片格式及其它 App 粘贴兼容性验收。原生往返和协议测试不能替代这些，也不代表远控视频跨平台和所有操作恢复已完成。
