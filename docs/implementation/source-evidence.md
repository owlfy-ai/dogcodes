## 如何阅读历史验收记录

历史文档中标为“本地证据”的路径仅用于定位维护者本机资料，公开 checkout 不包含这些文件。保留历史结论及其日期，不把缺失的原始证据冒充可公开复核的验收附件。源码中的固定样例、确定性测试与候选版本实际验收结果各有适用范围；旧记录不能代替当前三平台安装和异常恢复验收。

特别是会话删除等协议已发生变化，历史恢复/软删除流程不代表当前永久删除语义。重新执行实验须创建新的隔离数据，不能复用历史会话身份或操作正式用户数据。
