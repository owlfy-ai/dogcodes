## 2026-10-01：精简模型输入

- Core 在调用任何 Driver 前统一渲染模型正文；本地不可变交接 Artifact 仍保留 `deliveryFacts`、provenance 等审计字段，模型请求不再携带这些字段、安装 ID、冗余轮次索引及空字段。
- 原始聊天文字、用户约束、验收条件、决策、待办、测试结果、文件路径、实际补丁和历史查询入口继续保留，不调用模型生成摘要。
- 新构建的上下文不再重复附加成功变更事件的原始元数据；实际变更详情由 Core 读取 Artifact 后附加。只有已确认文件列表和补丁均为空的变更被省略，多目录补丁、二进制/预算省略提示、失败和未知状态保留。
- 投递凭据在本地提取，只在 Driver 接受请求后记录；省略的变更元数据不记为已交付。模型正文独立计算 SHA-256，`history.native_prompt_accepted.contextPayloads` 记录正文哈希、长度、渲染版本和原始 Artifact 引用。
- 已固化交接包不重写；旧包在发送时同样去除顶层审计字段，其已保存的正文保持原样。新包开始省略空变更。
- 验证：Core/Store 共 99 项单元及集成测试通过。对本机同一冻结历史范围只读重建预览，27 轮聊天全部保留；模型 JSON 从原 67,457 字节降到约 7,609 字节（减少 88.7%）。26 份普通空变更被省略，1 份中断后恢复状态仍保留；此验证未发送模型请求。

## 产品行为

Agent 选择只设置当前桌面对话的下一轮选择；发送前读取最新状态，自动构建、脱敏、固化上下文包，再提交用户输入。选择尚未发送时不创建交接 Artifact，不显示 Handoff Preview。运行中的执行者不受下一轮选择影响。未发送的选择是桌面内存状态，重启后回到持久化执行者。

内部 confirmed/sent 事件继续留存用于审计，普通对话时间线不显示这些内部条目。构建失败时保留输入、显示错误，不继续发送用户问题。

## 已实现

- ContextPackageV1 新增可选 conversationText，旧 Artifact 反序列化兼容；为空时不序列化，避免破坏旧 Artifact hash。
- 从冻结事件中的 turn.queued 和 message.delta 构建带 turn ID、用户角色、Agent 来源的原始问答，合并流式片段，不调用模型。
- Compact/Standard/Full 使用 16,000 / 96,000 / 256,000 UTF-8 字节正文预算，优先保留最近完整轮次；最新单轮超限时明确标记截断。JSON、审计信息不计入此正文预算，仓储仍执行包总大小限制。
- 明确告知模型未附带的历史不在当前输入中，内部 history locator 不可当作查询工具。
- 不再把 turn.completed 拼接成“已完成工作”。展示标题被明确标记为标题，不作为用户任务指令。
- Supported 的 active 与 resumable 目标均可路由到增量对账。实际恢复仍由 Driver 执行与确认。
- 发送时构建最新包，避免在选择 Agent 时过早冻结上下文。连续同一执行者不重复构建。

## 验证

Core/Store 集成测试检查 A 的原始提示词与回答进入 B 的实际请求，切回 A 时包含 B 的内容且不重复 A 的旧提示词。单元测试检查分片合并、来源、脱敏、UTF-8 预算和截断标记。前端测试检查自动确认先于 prompt、构建失败不发送、同一执行者不重复构建，以及 active/resumable 路由。

## 尚未覆盖

续批已实现 Git 逐轮净变化与有界变更文件版本存储，见 [M1-S5B](./m1-s5-turn-changes.md)。现已提供有界分页历史查询，见 [历史查询](./history-query.md)；仍不提供全项目可恢复快照，归因保持工作区时间区间。

分页浏览、字面全文检索、当轮 Agent CLI 查询和多目录文件版本已接入。超过 10,000 个源事件时取最新范围并声明省略。后续仍需逐事实交付覆盖、替换 lastSeenSequence 单游标假设与会话丢失自动重建；本项目不生成模型摘要。

确认与提交仍是两个版本检查命令；外部并发变化会使操作失败，用户重试，不自动掩盖冲突。只确认但未成功提交的包继续由现有重试路径处理。

本文件所述自动产品流程取代早期 M1-S5 文档中要求用户逐次预览与确认的桌面流程；保留底层不可变 Artifact 与 hash 校验。
