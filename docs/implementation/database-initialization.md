# 开发阶段数据库策略（2026-09-11）

> 发布范围说明：本文的原始运行资料仅保留本地，公开源码不包含；历史结论不替代当前版本验收。见[实验资料与证据政策](source-evidence.md)。

项目尚未发布，不支持旧数据迁移、数据库升级或降级兼容。

- 删除 DATABASE_VERSION、PRAGMA user_version、分版本迁移、ALTER TABLE 补列和启动自动回填。
- 完整 SCHEMA 一次性创建当前表、索引及 model/thinking 字段，仅对空库执行；已有库直接使用，不补表、不修复旧结构。
- 删除旧 host_interrupted 失败事件特殊解释、旧诊断 Timeline 行过滤及对应迁移测试。
- 保留只读损坏预检、检查超时、事务初始化、WAL，以及显式事件投影重建。它们服务于当前数据完整性和状态一致性，不承担升级。
- 保留当前 app-v5.db 路径，避免本次变更切换用户数据库。未读取、删除或迁移用户数据。旧开发库如与当前结构不兼容，需要开发者自行备份并重建；应用不自动清库。

验证：Core 24 项、Store 36 项、前端 190 项通过。覆盖新库创建、已有库重开保留已提交数据、损坏文件不修改、重开不自动补表、异常中断与断连状态重建。历史迁移验收记录不代表当前功能。
