# 本轮统计实测补充（2026-10-10）

根据用户的十张实际截图，核对绑定的原生会话，并用生产驱动对十二家 Agent 各执行两轮独立工作区、无工具的短对话。完整结果见 [脱敏实测数据](evidence/turn-statistics-2026-10-10/live-results.json)。该文件只包含状态及统计字段，不包含正文、私有思考、凭据、原生会话 ID 或本地路径。

## 已修复

- **CodeBuddy**：会话文件并非不存在。原生工作区目录保留大小写、空格及点号；旧代码额外转换这些字符，读错文件。修复后，用户原始会话可只读取得输入 28,082、输出 189、缓存读取 1,408、推理 104、原生模型 `hy4-preview-f`。新两轮请求账本分别为 1、2 条，重复读取不重复计数。
- **ACP 首个输出**：原生主会话的 Presentation 带有 sessionId，被 Core 原来的子流排除规则跳过。驱动现在为当前主会话首次非空文本/思考输出发送无正文的 FirstOutput 信号，每轮重置；工具输出、其他会话和 CodeBuddy 子任务均不触发。Kimi、Cursor、CodeBuddy、Grok、DeepSeek、Kiro、OpenCode 两轮均验证有首个输出等待时间。
- **原生模型**：Kimi 从绑定会话的 usage.record 读取模型；Codex 从原生启动/恢复响应及同线程、同 turn 的 rollout turn_context 读取模型，补到对应请求。Cursor 读取原生确认的当前模型。不会用模型选择器的显示文案冒充实际模型；`auto`/`default` 等路由模式不作为已解析模型展示。
- **Kimi 摘要归属**：使用原生 usage.record 时间构成摘要身份。连续两轮 token 数相同，也可以识别新摘要；没有新摘要时继续保留未知，不重复使用前轮数据。
- **ZCode 生成速度**：其原生 `session/debug` 另有已完成主请求的 requestId、usage 和 generationDurationMs。现在读取这个接口，校验 sessionId、主请求来源及 token 合计，在发送提示前后读取，按请求 ID 差集通过 UsageRecorded 事件流持久保存。拉取快照始终保留消息投影 ID；已有原生请求事实时不再叠加消息投影，接口失败时仍可沿稳定的消息 ID 回退，不把过去的请求重新归到下一轮。两轮实测生成区间 811 / 562 ms，输出 49 / 23，对应约 60.4 / 40.9 Tokens/秒。原生该接口没有返回的字段保持缺失。

## 各 Agent 的实际边界

| Agent | 已确认取得 | 当前缺失或限制 |
| --- | --- | --- |
| CodeBuddy | 本轮请求、模型、输入/输出、缓存读写、推理、Credits、首个输出 | 未返回美元费用；ACP 缓冲不能提供可靠生成速度 |
| Cursor | 原生模型、首个输出、本轮耗时 | 当前 ACP 不转发 Token/费用：本机 ACP presenter 仅处理文本、思考和工具；两轮均无有效 usage。绑定会话存储也未找到可归属请求的 Token 字段。CLI 内部存在用量，不等于当前 ACP 提供该数据 |
| Codex | 请求、模型、输入/输出、缓存读取、推理、首个输出 | 原生协议没有缓存写入和美元费用；未取得可靠逐请求生成窗口 |
| Grok Build | 原生单次调用的请求、模型、输入/输出、缓存/推理、费用、首个输出 | 多调用摘要不能拆为逐请求；ACP 缓冲不用于计速 |
| ZCode | 原生请求、模型、输入/输出、缓存、首个输出、原生生成计时 | 不以费用接口的账户数据填本轮美元费用；原生 debug 省略的推理字段不填零；旧版本可回退消息投影 |
| Antigravity | DONE 主响应的请求、输入/输出、缓存读取、推理、首个输出 | CLI 没有模型、缓存写入、费用或首 Token 时间；duration_seconds 包含准备/隐藏推理，不能替代生成窗口。此次本机元数据接口未成功返回额外模型信息，模型仍保持未知 |
| Kimi | 原生本轮摘要、模型、输入/输出、缓存读写、首个输出 | 无可确认的逐请求身份、单独推理、费用及生成窗口；不猜请求数 |
| Pi | 请求、模型、输入/输出、缓存读写、推理、费用、首个输出、生成速度 | 只显示原生实际提供的字段 |
| DeepSeek Harness | 请求、模型、输入/输出、缓存读写、首个输出 | 原生会话记录没有单独推理/费用/生成计时 |
| Kiro | 本轮 Credits 增量、首个输出、本轮耗时 | 当前原生摘要没有逐请求 Token 和可解析的自动路由实际模型；Credits 不转换为 Token 或美元 |
| OpenCode | 请求、模型、输入/输出、缓存读写、推理、费用、首个输出 | ACP 输出可能缓冲，不据此计速；使用应用发现的 2.0.18 CLI 和可用 Big Pickle 实测 |
| Claude Code | 请求、模型、输入/输出、缓存读写、推理、首个输出、生成速度 | 本机供应商此次没有原生美元费用；不使用价格表估价 |

这不是断言某家 Agent 永远不提供某项数据。结论限定于本机安装版本、已接入接口和本次实测。逐请求真实计时可用时展示生成速度；不能将终端文本缓冲后的到达间隔当作服务端生成耗时。

## 浮层

已移除“统计范围”“数据完整性”“数据说明”“计速范围”及“本轮用量暂无数据”行。缺失指标直接省略，保留实际的 Agent、耗时、首个输出、模型及 Token/费用数据；首个输出与速度也不再附带括号说明。

内部的范围、完整性及缺失原因仍随历史保存，供恢复和诊断使用，不在用户浮层展示。已经冻结且没有保存用量的历史轮次不根据最新累计值补写；新采集逻辑在之后的新轮次生效。旧轮次的说明行会立即随 UI 更新消失。
