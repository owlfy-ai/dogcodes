# 终端按身份自动连接

日期：2026-10-17。用户要求移除“恢复终端”按钮，打开终端时按自身标识自动恢复连接。

## 当前行为

- 删除终端工具栏“恢复终端”按钮。收起再打开终端面板时自动查询后台资源，发现已有终端后按原 ID 连接，不新建同目录的替代进程。
- 关闭单个终端标签仍只隐藏输出，不停止进程；在“+”菜单的“已有终端”中选择该终端即可重新打开，其下单独列出新建终端选项。各终端保留自己的标签身份和后台资源 ID。
- 首次发送启动前即把操作身份交回父视图保存，成功后记录返回的资源身份。隐藏、重开和启动回执丢失时，重新连接原身份，不生成新启动请求。
- 可见终端连接失败后自动重试，仅查询/连接原资源；延迟从 1 秒递增，最多 15 秒。隐藏时暂停重试，再次显示时立即连接；在途连接未结束不叠加请求。成功连接后重置等待时间。
- 去掉终端状态行的手动重新连接按钮，保留友好错误提示和自动连接反馈。输入结果未知时丢弃待发送队列，绝不自动重放输入。
- 已退出、启动失败或后台明确返回 Unknown 的资源显示实际状态，不自动启动进程。无法找到旧 ID 时继续核实，不能退化为重新执行。
- 项目运行输出使用实际运行 ID。共用的项目运行适配器在首次启动尝试后也只允许重新连接；重新打开输出不能在查询失败时再次发送运行命令。

## 改动与验证

修改 `TerminalDock.tsx`、`ProjectRunPanel.tsx`、`projectRunClient.ts` 及对应测试。未修改 Rust、数据库、终端协议或进程控制语义。

最终 53 项不同前端用例通过：TerminalDock 22、ProjectRunPanel 19、projectRunClient 5、terminalClient 4、terminalInput 3。其中最后两组在首轮通过且之后未修改，不重复运行；新增行为组修正后复核通过。覆盖独立终端重开、资源发现去重、断线退避/隐藏暂停、在途连接、未知状态、丢失回执不重启和输入不重放。前端类型检查与 diff 空白检查通过。

未重新编译原生程序或打包；三平台窗口/后台实际重启仍按桌面发布候选计划验收。旧生命周期记录中的手动恢复入口描述仅为历史状态。

## 同日后续：关闭当前终端

用户进一步要求移除单独的停止按钮，将原工具栏“收起终端”× 改为结束当前进程，文案统一为“关闭当前终端”。按当前选中标签保存的资源 ID 发送关闭请求，成功后关闭该标签（不再列在已有终端菜单），最后一个标签关闭后收起面板。关闭请求失败不隐藏标签，关闭过程中防止重复请求；其他终端和单标签隐藏输出行为保持原语义。原生终态仍由后台提供，不把请求成功当作进程已退出。

新增当前终端隔离、失败重试、关闭在途防重复用例；25 项 TerminalDock、19 项 ProjectRunPanel 前端用例及最终类型检查通过。删除废弃的 TerminalPane 停止控件、restartable 参数和专属样式，未修改原生服务。
