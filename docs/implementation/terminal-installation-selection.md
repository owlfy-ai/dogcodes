# 按终端命令选择 Agent 安装

一个 Agent 只注册和展示一份选中的安装。默认按终端命令选择，不按额度是否可读来挑选。2026-09-29 增加下述 OpenCode 共用数据库的版本兼容例外，不迁移历史会话。

## 选择规则

1. 在用户的登录交互 shell 中执行 `command -v`，读取内置 Agent 命令的位置；只解析命令，不启动 Agent。解析软链接，得到实际可执行文件。
2. macOS 从 Finder 启动且没有 SHELL 环境变量时，查询用户配置的登录 shell。探测有超时和输出大小限制，并在用户主目录执行，避免项目目录影响命令查找。
3. 多个 Agent 的并发检测共享一次 shell 查询，短暂缓存两秒。每个 Agent 只对选中路径进行版本、连接、额度探测和驱动注册。
4. 没有终端命令的客户端可使用清单中明确声明的安装入口，例如 ZCode.app。不再遍历 NVM 的全部安装版本。
5. 自定义别名、函数或失败的 shell 查询不能证明实际安装位置时，显示可处理的检测提示，不猜测另一份安装。
6. 欢迎页只显示一个“安装位置”。Agent 选择器、审查助手、帮助恢复及额度面板使用同一份后端选择结果；额度暂不可用时也不会借用另一份安装的读数。

## OpenCode 兼容例外（2026-09-29）

macOS 的默认 `~/.opencode/bin/opencode` 若为 1.x，且存在桌面托管 2.x 或更新 CLI，则在身份和版本验证通过后使用该托管 CLI，避免旧 CLI 访问已升级的共享数据库失败。没有终端安装时也支持此发现入口；不覆盖自定义命令、不修改数据库，终端已为 2.x 或更新版本时仍优先使用终端。详见 [修复记录](agent-conversation-failures-2026-09-29.md)。
