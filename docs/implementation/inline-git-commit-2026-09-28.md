# Diff 面板内联 Git 提交（2026-09-28）

## 交互

右侧变更文件列表上方以提交说明输入框替代原“搜索文件”框。工作区文件浏览页的搜索保留。输入框右侧星光图标展开可用 Agent 列表，选择后直接生成并回填提交说明，记住所选 Agent；生成失败保留原文案。支持手动编辑和 Cmd/Ctrl+Enter。

输入框下方为 Commit 分体按钮，下拉选择 Commit 或 Commit & Push，再点击主按钮执行。移除旧提交/推送工具栏图标和模态弹窗。仓库名及悬停完整路径表明操作目标；操作期间禁用目录/文件切换和冲突操作。

Git 语义保持：有暂存更改时只提交暂存内容；无暂存更改时在面板内明确确认是否暂存全部（包含新增文件）。Commit & Push 在提交成功后才调用原上游推送命令；提交失败保留文案且不推送，推送失败明确说明提交已完成，主按钮变为“重试推送”，避免再次提交。

移除文件筛选后不再应用独立窗口旧 view 中的 filter 字段，避免文件被不可见的筛选隐藏。非 Git 目录禁用提交及 AI 生成。

## Agent 行为

使用原生默认模型（用户允许默认模型或上次选择模型）；读取该模型实际公布的思考选项，优先 off/none/disabled，其次 minimal、low 等最低支持档位，不按列表顺序猜测。原生接口未提供默认模型或可识别思考档位时保留原生默认值，不伪造可选参数。

提示词要求快速输出一句简洁中文提交说明，尽量不超过 50 字，不解释、不列清单、不调用工具，不声称已测试或提交。Git 内容作为 JSON 数据提供。对共享连接的 Agent 使用独立驱动实例，防止总结会话影响主对话；保留完成/失败/超时后的释放流程。

不引入 ExecutionRun 或审计 artifacts。生成说明不会自动提交。
