## 已修复

- 终端原先只保留最近 32 个结束会话的输出内容，但对更早的缓冲区调用 `clear()`，内存容量一直保留。现在丢弃旧缓冲区的分配，保持原输出偏移、终端身份与执行回执；重新读取明确报告缺口。运行中、启动中、停止中的终端不受清理影响。选择保留项使用最多 32 项的辅助集合，不再克隆全部历史终端的命令与元数据、排序所有结束会话。
- 永久删除会话后的持久清理队列，现在同时关闭对应内置历史 MCP 监听器、撤销访问并移除 endpoint 缓存。最后一个执行引用释放时删除其临时配置。此队列来自已经持久化的永久删除事实；普通查询失败或列表缺失不会触发清理。普通轮次结束与取消继续保留原端点，避免破坏原生会话复用；其他会话的端点保持可用。
- 九种语言 README 同步实际后台行为：隐藏项目输出或关闭桌面窗口不会停止项目命令，用户通过运行面板的停止动作结束进程。
