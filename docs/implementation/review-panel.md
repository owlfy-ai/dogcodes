# Review / Diff

## 产品边界

这是编程 Agent 的工作区差异查看功能。差异反映磁盘状态，不归因于某个 Agent。

- Git：Uncommitted、Unstaged、Staged、Committed、Branch；支持提交分页和选择合并提交的父版本。
- 非 Git：首次执行前保存会话初始基线，切换 Agent、重开存储均沿用同一基线。
- 多目录、文件树、变化统计、文件类型信息、二进制提示。顶部按“目录 → 比较方式 → 提交/分支”级联；多目录默认“所有目录”，单目录隐藏目录选择。非 Git 目录标注“未使用 Git”，同名目录用完整路径区分。
- 左侧仅显示目录名，目录总增删行数与文件增删行数采用绿/红色；文件状态为 M/U/A/D/R。支持目录折叠、紧凑单子目录路径、浅色/深色主题。常规界面不展示绝对目录路径、基线哈希或数字文件模式。
- 所有 Git 目录支持汇总全部未提交、未暂存、已暂存；混合项目默认“当前改动”（Git 未提交 + 非 Git 会话变更），未暂存/已暂存标注“仅 Git”并由后端过滤。全非 Git 或选定非 Git 目录仅展示会话变更，不提供 Git 比较选项。历史提交/分支比较只在选定一个 Git 目录后提供。
- 目录选择独立于文件选择；选定目录后，列表、统计及新审查的冻结输入仅包含该范围，不混入其他目录旧快照。切换目录保留适用模式，清除提交/分支、文件和预览；分离窗口保留目录范围。从对话定位其他目录文件时回到全部当前改动。实现与验证见 [目录级联](review-directory-scope-2026-09-26.md)。
- 行内/左右对比、上下文展开、冻结阅读和显式刷新。
- 当前任务关闭再打开保留阅读快照，后台检查新变化并提示刷新；切换任务释放旧阅读状态。重复在途查询合并，多目录最多同时读取三个，结果顺序保持。
- 暂存/取消暂存；普通文件丢弃/撤销，重命名按两路径成组处理。
- 子模块展示提交指针和脏状态，可暂存/取消暂存提交指针；不恢复子模块内部内容。

## Git 提交

变更文件列表顶部使用提交说明输入框，右侧图标选择 Agent 生成简洁文案；下面的分体按钮选择 Commit 或 Commit & Push，移除旧提交/推送图标及弹窗。优先提交已暂存内容，无暂存时在面板内确认暂存全部。推送失败保留“已提交”结果，只重试推送。AI 使用原生默认模型及其最低支持思考档位；未公开思考参数时保持原生默认。实现与验证见 [内联提交](inline-git-commit-2026-09-28.md)。

## 侧栏与独立窗口

右上角仅保留“显示底部终端”和“显示右侧边栏”两个图标按钮，移除固化快照、Artifacts 入口和本地状态标签。Diff 在主窗口占用贯通上下的右侧布局列，打开时压缩中间聊天和底部终端的宽度，不覆盖二者。标题栏的“分离为独立窗口”创建可移动、缩放的原生窗口，并传递选中文件、比较模式及对照选项。独立窗口固定所属任务；主窗口切换任务不改变它。再次点击该任务的右侧边栏按钮会聚焦已有 Diff 窗口。

“回到侧栏”或关闭独立窗口会收回当前任务的侧栏；若主窗口已切换到其他任务，不强行切换任务。独立窗口使用自己的冻结快照，重新读取最新文件，不共用可写前端状态。后端 Diff 命令校验窗口标签与任务绑定，其他任务的 Diff 请求被拒绝。

## 底部终端

终端与中间对话区同宽；项目主目录和每个附加目录各有一个独立 Shell 标签页。标签只显示目录名；同目录新增终端附加序号。终端右上角“＋”在单目录项目直接新建，在多目录项目先弹出目录选择浮窗；新建后自动选中新标签，已有会话保持运行。每个标签的关闭按钮结束该会话；关闭当前标签后选中相邻标签，全部关闭后仍可通过“＋”新建。支持键盘输入、彩色输出、Ctrl+C、标签切换和拖动上边缘调整高度。收起面板保留会话；退出 Shell 后可重新打开。切换项目或离开对话视图会释放当前面板及其会话，同一项目内切换任务保留终端。

终端使用 xterm.js 和 portable-pty，通过 Tauri Channel 传送原始 UTF-8 字节。终端只在首次打开时加载。主窗口传项目 ID 与目录序号，后端从项目元数据解析工作目录；独立 Diff 窗口没有终端命令权限。终端输出不写入聊天历史或 Diff 快照。

- `apps/desktop/src/ReviewPanel.tsx`：查看侧栏。
- `TerminalDock.tsx`、`terminal.css`、`apps/desktop/src-tauri/src/terminal.rs`：终端标签、布局和 PTY 生命周期。
- `ReviewText.tsx`、`ReviewFileTree.tsx`、`ReviewReadAnchor.tsx`：差异正文、目录树和阅读位置。
- `ReviewRecoveryActions.tsx`：普通文件确认及丢弃记录。
- `reviewClient.ts`：查看、索引操作和普通文件操作的 IPC。
- `apps/desktop/src-tauri/src/review.rs`：任务/项目范围校验、快照缓存及普通操作入口。
- `crates/workspace/src/review.rs`：快照与非 Git 基线。
- `review/git.rs`：Git 比较；`git/operations.rs`：单文件索引操作；`git/index_lock.rs`：标准 Git 索引锁。
- `review/recovery.rs` 和 `recovery/{transaction,group,index}.rs`：普通文件备份、配对操作和索引发布记录。
- `review/storage.rs`：内部缓存容量、引用保护与快照生命周期。

## 已移除的扩展

子模块恢复预览、HEAD/index/工作树联合恢复、多仓库整树续作/撤销、文件/目录拓扑重建、孤立候选目录处理、Git 锁归属管理与隔离、暂存恢复操作台、侧栏缓存管理，均已退出产品。专用前端、桌面命令、库执行代码和故障验收脚本一并删除。

Git 锁回归标准 `index.lock` 独占创建；遇到已有锁就报错，不猜测归属或隔离锁。正常退出只移除本次仍持有的锁。进程异常退出后的 Git 锁由常规 Git 工具/操作者处理。

## 保留的保护与数据兼容

路径边界、符号链接访问限制、扫描预算、冻结快照、持久基线、普通文件备份和后续修改校验继续保留。普通文件事务已有的权限/所有者/ACL/扩展属性保护仍随普通丢弃与撤销保留，避免裁剪直接改变已有文件元数据；不再扩展为完整文件系统恢复要求。

没有删除用户的基线、恢复记录或缓存。旧高级恢复记录不再提供执行入口。缓存仍保护旧持久引用，旧目录恢复清单仅保留读取 metadata_hash 的兼容处理，无目录恢复执行能力。内部缓存维护保留，侧栏不再提供占用、回收、容量设置操作台。

## 验证

`pnpm check`：类型、前端测试、构建。

`cargo test -p agent-workspace --lib`：Git 模式、索引隔离、普通丢弃/撤销、基线和缓存保护。

`cargo test -p desktop --lib --features review-acceptance`：桌面边界及隔离 fixture。

原生 `review-acceptance` 保留普通文件、Git 模式、多目录及真实多 Agent 验收入口；已删除高级恢复的脚本。设置 `DOGCODES_REVIEW_MANUAL=1` 可生成隔离数据后手动操作，不自动执行 UI 脚本。真实 Agent 验收只在需要时运行，避免重复消耗额度。

## Agent 菜单统一（2026-09-29）

主对话、逐轮/项目审查、Git 提交说明生成、运行命令分析共同使用 `AgentPickerMenu` 和 `agentPicker.css`。菜单使用主对话的 20px 图标、44px 行高、额度环、选中状态及浅深色主题；复用 FloatingPopover 的避让定位与滚动处理。周围文件列表和运行面板的按钮样式不会覆盖菜单行。

额度直接读取已有 `AgentQuotaContext` 或调用方传入的读数，展开菜单不触发额度查询。选择行为保持各入口原语义：主对话切换下一轮 Agent，审查只选择审查者，提交说明点击后生成，运行命令保留自动选择且不会被目录轮询覆盖。Escape 与点击外部可关闭菜单。

验证：7 个相关测试文件共 30 项通过；类型检查和前端构建通过；浏览器确认四种父容器下浅深色菜单尺寸一致、滚轮正常。全量测试 452/454 通过，两项未通过为归档会话删除与草稿项目选择，未将全量标为通过。

提交区不再单独显示仓库/项目名。当前选中的仓库没有 Diff 文件，或目录不受 Git 管理时，隐藏提交说明和提交按钮；Git 仓库中的新增文件仍可进入正常暂存提交流程。若提交完成后推送失败，即使 Diff 已清空也保留“重试推送”，成功后再隐藏，避免丢失重试入口。
