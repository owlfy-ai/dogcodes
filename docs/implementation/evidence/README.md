# 历史验收摘要

此目录保留历史隔离实验的统计、状态摘要及经过脱敏的示例审查报告，不是原始 Agent 会话归档，也不是当前发布候选的验收证明。适用版本、平台和限制以对应实施记录为准；悬浮岛和软删除/恢复等旧流程不代表当前产品行为。

2026-10-16 的公开整理对 9 份摘要中的真实任务、轮次、审查、安装、产物和原生会话标识使用一致的 `example-<类型>-<编号>` 别名；同一原始值在本目录中使用同一别名，不同值保持区分。别名不是可提交给 API 的真实 ID。四个临时目录前缀改为 `[LOCAL_TEMP]`，不能作为可运行路径。原始副本及别名映射只存放在被 Git 忽略的本地私有目录。

整理保留 JSON 的键、结构、数字、布尔值和 null，不改变执行状态、失败原因、用量、计时或内容摘要。身份别名化仅用于公开文档，不改动产品存储或真实会话；这些 JSON 不被应用测试作为输入读取。

审查报告中的 `payments/withdraw.py`、`reports/last.py` 等是隔离验收示例；发现项正文仍需按原报告边界理解。其他摘要的内容审阅和历史版本审计继续进行，不能仅凭本说明认定全部资料已经适合公开。更多边界见[源码证据政策](../source-evidence.md)。
