# 侧边问答的统一安装准入

对应 DT-09/DT-10，接续[Agent 启用准入](desktop-sidebar-chat-admission-2026-10-16.md)。这是侧边问答路径的收敛，不代表所有 Agent 执行入口已验收。

## 缺口与修复

之前只有 Tauri 的 `core_sidebar_chat_agents` 在返回候选列表时筛选 Ready 安装，Core/daemon 列表和新问答受理只依赖内存驱动。重新检测把安装状态改为 Installed/NotConfigured/UnsupportedVersion/Broken，或存储已记录安装移除时，内存可能仍保留原驱动；直接调用后台或使用旧窗口仍可能发起新问答。

安装筛选现在位于 Core，候选列表与新问答受理共用检查：provider 与明确的 installation ID 均匹配、安装状态为 Ready、安装属于当前选择，并存在支持只读问答的驱动。没有安装身份的 executor 不再被视为可启动问答。Tauri 保留窗口范围检查并直接转发后台结果，减少第二次 bootstrap 查询；成功 JSON 形状和现有命令名称不变。

后台设置、安装探测结果、安装移除、当前安装选择及驱动注册与新问答受理使用同一 Core 读写门禁。已完成的不可用状态不会被旧快照绕过；旧路径的驱动迟到注册，也不能绕过当前安装选择。Ready 记录和驱动必须同时存在，任一缺失都返回不可用；没有重新探测、启动安装流程或自动更换 Agent。

已受理问答持有自己的驱动和取消句柄。后续探测失败、切换安装或移除安装不使它隐式结束，也不阻断原回执查询、相同请求重放或停止。读取原回执仍优先于新工作检查；新请求被拒绝时不会留下受理回执。

## 验证

一次集中顺序执行 `cargo test -p agent-core --lib --locked` 和 `cargo test -p desktop --lib --locked sidebar_chat`：**80 项 Core 测试（含 15 项问答测试）及 5 项桌面问答专项全部通过**。进程 62403 已 exit 0。日志为 `/tmp/dogcodes-sidebar-readiness-core.log`、`/tmp/dogcodes-sidebar-readiness-desktop.log`；`git diff --check` 通过。执行期间仅补充文档和两处注释，没有继续更改运行逻辑或重复验证。

新增证据覆盖：

- Core：四种非 Ready 状态、缺失/错误安装 ID 均不能启动问答；设置恢复 Ready 后候选恢复。确定性并发测试中，先排队的安装降级必须阻止随后到达的新问答。
- SQLite 与真实 loopback RPC：先受理问答，再把安装降级；恢复 Ready 后更换当前安装，模拟旧驱动迟到注册；最后移除安装。各阶段新请求均被拒绝，原回执、查询和停止始终可用，原生会话只启动一次。
- 既有禁用设置、原请求重放、清空、后台空闲退出及问答历史恢复回归继续纳入本次验证。测试夹具保存真实结构的安装探测事件与安装 ID，没有为测试驱动加入生产例外。

本轮没有第三方依赖、协议命令或数据库结构变更，没有前端构建、生产打包、签名配置修改或真实 Agent 调用。
