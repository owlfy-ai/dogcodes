# 启动与日常交互体验整理

## 已完成

- 首帧：原生主窗口默认隐藏，在前端已提交带主题的界面后显示。兼容隐藏 WebView 不触发动画帧的情况；页面资源异常时原生窗口仍有延迟显示兜底。
- 在应用模块加载前恢复主题、缩放、侧栏宽度和收起状态。HTML 首帧、服务检查和工作台读取使用同一套安静的占位布局，不再出现“正在启动本地 Core”等内部阶段提示。
- 启动模块并行预加载；独立文件审阅页面改为按需加载，减少主入口代码。加载超过 12 秒提供重新打开入口；模块或渲染异常提供恢复页面。
- 服务不可用时提供明确的应用重启操作；工作台读取失败可重新读取。重试成功清除之前的错误提示。存储异常保留保护措施，备份说明与诊断细节默认折叠。
- 移除设置中的无响应菜单、未实现的远程连接入口、空白运行/调试标签；历史记录与恢复页面使用更易理解的说明。
- 模型列表失败可直接重试，刷新时保留当前模型名称；模型与思考强度菜单关闭后分别恢复正确焦点。
- 权限列表加载与空列表分开显示；缺少权限接口不会无限等待；选择后回到触发按钮。
- 创建项目可从第一个文件夹自动填入名称；选择文件夹时不会误显示“正在创建”。保留用户输入的名称。常见权限、磁盘与连接错误使用可操作的说明。
- 提交说明助手显示 Agent 名称，隐藏安装内部 ID；复制反馈短暂显示后恢复；补齐全局键盘焦点与减少动态效果支持。

## 验证

- 前端全量：79 个文件、341 项测试通过。
- 最后涉及启动恢复的调整：4 个文件、10 项定向回归通过；另补充应用重启成功、失败两项用例并通过。
- TypeScript 与生产前端构建通过；原生 Rust 编译通过。
- 浏览器视觉检查：工作台、深色启动页、浅色恢复页、折叠处理步骤。
- 隔离原生构建可启动并完成测试数据初始化；系统界面检查工具读取测试应用超时，未完成原生逐帧录屏验收。临时预览文件与测试应用已清理。

## 验证边界

此次整理覆盖启动与常用交互，不等同于所有 Agent、网络异常和操作系统组合的完整发布验收。额度、权限、文件操作的事实性限制仍保留；诊断与文件审阅中有助于理解操作后果的信息不会简单删除。浏览器的离线演示数据仍明确标示为演示，不冒充真实账户状态。
