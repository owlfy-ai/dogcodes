# 项目运行方式自动分析与一键运行：现有功能核对

日期：2026-10-14。此记录补充已实现功能的文档遗漏，不代表本日新增实现或重新完成全平台验收。

## 界面与能力

用户提供的 DrillHUD 截图显示右侧「运行」页，包含分析 Agent 选择、重新分析，以及桌面调试、前端开发服务、生产构建、产物预览、资源准备、测试和 macOS 构建等运行项。各项名称由项目分析结果决定，不是应用硬编码的固定菜单。

- 按项目目录分组展示运行项；悬停可查看实际命令、工作目录及来源文件。
- 选择可用 Agent 分析项目运行方式，支持重新分析。
- 点击运行项在内嵌终端执行，多个命令有独立输出标签，支持输入、停止及结束后再次运行。重复点击当前面板中仍在运行的命令会切换到其输出。
- 支持重命名、固定和删除。重新分析保留固定项；覆盖未固定的用户修改前确认。
- 分析结果按项目和平台保存为本地 JSON，跨桌面重启读取；未完成分析在重开时标为中断并提示重新分析。

扫描覆盖 README、常见语言/构建配置、Makefile/Justfile、容器配置、包管理器锁文件线索及 shell/PowerShell 等脚本。扫描有深度、文件数及字节预算，跳过隐藏项、依赖/构建目录和符号链接，不意味着完整读取所有项目文件。

Core 将文件内容、平台和 shell 交给所选 Agent 的独立分析 Session，要求返回有来源的启动、调试、构建、测试或部署命令。分析会实际调用 Agent；列出命令后，由用户点击对应项目执行。宿主校验来源文件、项目内工作目录、单行命令及目录/配置版本，避免使用过期配置。

## 能力边界与验证依据

- 「调试」指运行项目已有调试命令，不是内置断点、变量检查等通用调试器。
- 当前编辑操作为名称、固定和删除；未提供命令正文或工作目录编辑器。
- 预览可作为项目命令出现；未发现专门的预览 URL 识别入口。
- 运行进程属于桌面终端宿主，关闭输出或所属窗口会清理进程；不能套用 Agent 在独立 Core 服务中继续执行的承诺。
