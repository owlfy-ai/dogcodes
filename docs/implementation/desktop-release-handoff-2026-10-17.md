## 7. 不应改变的约束

- Core 保持独立于 Tauri/UI；复用规范事件、投影和回执，不另造矛盾事实源。
- 同项目允许多个会话/Agent 并发，不增加项目级单写者锁或强制 worktree。
- 幂等请求优先查询原回执并核对载荷；受理不等于执行完成，取消受理不等于进程已停止。外部副作用结果未知先核实，不自动换新 ID 重做；PTY 输入不重放。
- 已受理执行保持原安装/driver，更新偏好只影响后续工作；审批绑定原 run/turn/request sequence。
- 不新增数据库迁移、兼容回填或自动清空用户数据；不删除项目源码、原生 Agent 历史或用户凭据。
- 审查使用独立会话、提示词要求只审查；“开始修复”仍交给主 Agent，并携带报告/选中问题上下文，不改回按审查 Agent 修复。
- 不恢复悬浮岛。不把端内草稿、主题、布局、待发送模型/思考强度强行同步。
- 有活跃 Cargo 时等待原命令；超时返回不等于进程结束，句柄失效需核实进程/日志再重启。不得结束不属于自己的进程。
- 每块完成后更新当前状态和证据；不将已有功能重新实现，也不将本机专项通过扩大为全平台发布就绪。
