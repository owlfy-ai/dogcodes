# Diff 目录与比较方式级联（2026-09-26）

## 行为

- 多目录项目按“目录 → 比较方式 → 提交/分支”选择，默认所有目录；单目录隐藏目录下拉。
- 指定 Git 目录提供全部未提交、未暂存、已暂存、历史提交、分支比较；指定非 Git 目录仅显示会话变更。
- 所有 Git 目录可汇总前三种模式；混合项目默认“当前改动”，汇总 Git 未提交与非 Git 会话变更。未暂存/已暂存标注“仅 Git”，后端只纳入 Git 目录。全非 Git 项目仅显示会话变更。
- 选定具体 Git 目录后才提供历史/分支；切换目录保留适用模式，并清除原提交、分支、父提交、文件和预览。不适用的模式回到当前改动。
- 文件点击不改变目录筛选；多目录文件列表显示目录分组，非 Git 分组标注会话变更。同名目录在下拉中用完整路径区分。
- 列表、文件计数、行统计及新审查共用后端返回的同一个冻结快照，移除拼接其他目录旧快照的导航行为。审查结果与原材料重试继续保留历史来源。
- 非 Git 基线不可用仍显示读取失败，禁止发起假完整审查，不展示为没有改动。
- 分离窗口保存目录范围；从对话跳转到工作区文件时回到所有目录的当前改动，并准确定位文件。

## 实现

`ReviewPanel` 将 `directoryId`（比较范围）与 `rootId`（文件/Git 操作焦点）分开。目录清单独立于筛选快照，暂存相关汇总不会让非 Git 目录从选择器消失。`core_review_query` 在生成快照前验证范围：跨目录历史/分支被拒绝，指定非 Git 目录的 Git 比较被拒绝，暂存汇总只纳入 Git 目录。沿用原有冻结、租约、并发上限和快照存储机制。
