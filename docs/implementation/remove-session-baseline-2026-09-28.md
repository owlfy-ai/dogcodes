# 取消启动前的非 Git 会话基线

按当前未发布阶段的产品决定，不迁移或兼容旧会话基线。本记录替代审查简化记录中“保留非 Git 会话基线”的决定。

## 行为

- Agent 启动前只校验所选目录存在，不再调用会话基线构建、扫描目录或保存首次完整基线。计时阶段由 `review_baseline` 改为 `workspace_validation`。
- Git 比较继续使用 Git。
- 非 Git Diff 面板改为“已记录修改”：从本会话已有的逐轮撤销记录取得每个文件第一次被记录修改时的原始内容，再与当前文件比较。只读取已记录路径，不扫描未涉及的文件，也不读取旧会话基线兜底。
- 没有记录时返回空列表；记录损坏、内容不完整或读取失败时报告错误，不补做全目录基线。跨目录同名文件独立处理，已恢复到原始内容的文件不再显示差异。
- 面板说明比较范围：未记录文件的外部修改不保证出现在列表中；Agent 审查仍可读取当前项目代码。
- 整轮撤销、文件恢复及恢复事务保留。逐轮修改前内容仍由原有捕获链路保存，既有内容和范围预算未扩大，也不以旧会话基线替代缺失的撤销记录。

没有迁移旧数据，也没有批量删除本地 `review/`，因为它仍保存撤销/恢复和 Diff 展示所用内容。新的执行与非 Git Diff 路径不依赖该目录中的会话基线。

## 验证

新增测试验证：目录校验不创建 Review 存储、无会话基线的新任务可读取逐轮记录、按首条修改记录汇总、跨目录同名文件隔离、读取当前内容、排除未记录的大文件、恢复后移除差异以及路径越界拒绝。

同时运行 Core、Store、Workspace 和 Desktop 默认测试，以及前端 ReviewPanel/TurnFiles 测试和 TypeScript 检查。撤销与恢复沿用 Workspace 的文件、二进制、多根目录、漂移校验和持久恢复测试。

上述默认回归全部通过；新增桌面记录查询测试 2 项通过，前端相关测试 35 项通过，生产构建通过。

## 新对话实测

在原 DrillHUD 项目用 Cursor 新建只读诊断对话，要求只回复测试文字、不调用工具。确认新任务没有生成会话基线文件；启动日志不再出现 `review_baseline`，目录校验 `workspace_validation` 仅 0.03ms，原先单次实测约 14.1 秒的基线准备阶段已移除。

本次原生会话初始化 4.54 秒，提示词提交至首段正文 3.38 秒，Core 接收提交至正文发布合计 9.02 秒。单次样本仍受原生会话和服务端响应波动影响，不能把目录校验耗时当作总启动时间。诊断对话结束后已归档。
