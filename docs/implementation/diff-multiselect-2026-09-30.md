# Diff 文件多选与批量操作

2026-09-30，按用户要求在右侧 Diff 文件列表增加框选和组合键多选，并接入批量索引操作。

## 交互

- 普通点击选择一个文件并打开预览；Shift 点击按当前可见顺序连选，Ctrl / macOS ⌘ 点击增减选择。Ctrl/⌘ + Shift 点击追加范围。
- 鼠标从文件行或空白处拖动框选；按住组合键可追加，靠近上下边缘自动滚动。小幅移动仍按普通点击处理。拖动取消恢复原选择。
- Ctrl/⌘ + A 选择当前展开的文件，Esc 清空选择。列表和树形视图都适用；同名文件按仓库和完整路径区分。
- 多选及框选不切换右侧预览。比较范围切换清空选择；刷新移除已不在快照中的文件。
- 多选后通过右键菜单执行批量操作，在“已暂存”范围提供“取消暂存所选”；右击未选文件改为该文件的菜单。列表上方不显示常驻选择工具条。

## Git 边界

- `core_review_index` 接收路径数组，单文件入口也复用此协议。桌面前后端需一起更新。
- 同一仓库的全部选中文件共用一次私有候选索引和发布事务：先验证快照、目录范围、文件内容、HEAD 和索引版本，再在真实索引锁下重新校验并发布。保留已有工作区写入租约和活动任务限制。
- 重命名同时处理源、目标路径；先移除旧条目，再写目标条目。去重路径，不改未选文件的暂存内容，也不修改工作文件。
- 恢复记录扩展为最多 4,000 个路径（2,000 个变更各带两个重命名路径），清单读写统一限制为 4 MiB；旧记录仍可读取。
- 多仓库按仓库依次执行；失败即停止，提示已完成数量和失败仓库、刷新列表，保留未完成选择。跨仓库不是一个原子事务。
- 混合非 Git / 不支持索引操作的比较范围会禁用批量暂存，不静默跳过部分选择。批量丢弃与忽略规则的后续补充见下节。

## 后续补充：简化选中样式、批量丢弃与忽略规则

- 按用户反馈移除选中行左侧色条，仅保留背景高亮。
- 工具条新增“更多操作”，与多选右键菜单提供暂存/取消暂存、加入 `.gitignore`、丢弃所选更改。菜单支持方向键导航。
- 丢弃前显示冻结的所选文件清单、完整仓库路径、恢复基准（HEAD、暂存区或会话初始版本），说明新增文件删除、重命名处理及暂存区不变。取消不写文件，执行中阻止重复提交与关闭确认框。
- 批量丢弃新增后端命令 `core_review_batch_files`。先验证任务授权、项目范围、快照、比较方式及全部成员；Git 比较在索引锁下复核。备份与替换内容全部准备后再逐个应用现有恢复事务，修改前再次检查文件版本。子模块、重叠路径和文件/目录互换拒绝批量丢弃。
- 批量工作文件操作不宣称文件系统原子性。执行中失败返回明确的已完成路径，保留备份和未完成选择并刷新；单个重命名也可能部分完成，错误会提示检查和恢复记录 ID。
- 批量忽略仅接受未跟踪文件，混入已跟踪文件或重命名即禁用并说明原因；后端重新检查真实索引。按项目 scope 分组，在对应 `.gitignore` 中一次追加字面路径规则，保留已有内容及换行风格、去重并转义特殊字符。预检查所有目标文档，拒绝符号链接和无效文本；跨目标失败返回已完成路径。
- 验证：前端相关 82 项通过（ReviewPanel 64、文件树 6、选择交互 8、客户端协议 4）；workspace Review 回归 121 项通过、10 项现有忽略；desktop 批量操作边界 2 项通过。新增真实临时 Git 仓库用例覆盖恢复修改/新增/删除/重命名、未选文件与暂存区保留、过期文件与无效备份、忽略规则去重转义、分 scope 写入和符号链接拒绝。
- workspace / desktop all-targets 严格 Clippy、修改的 Rust 文件格式检查、前端类型检查与生产构建通过，仍保留已有分块体积提示。浏览器 520 × 800 验证更多菜单和丢弃确认清单，截图 `/tmp/dogcodes-batch-actions.png`。页面为模拟数据；未对用户仓库执行丢弃、忽略，也未重打包原生应用。
- 讨论中的后续候选：复制所选文件相对路径、导出所选 Diff、仅对所选文件发起 AI 审查，本次未实现。


## 界面收简：移除选择工具条

按用户要求移除整条常驻 UI，包括“拖动框选 · Shift 连选 · ⌘ 多选”提示、已选数量、暂存、更多操作和清除按钮，同时删除对应状态、属性和样式。框选、组合键多选、Esc 清空及右键批量操作继续可用。已有测试改为从右键菜单操作，82 项前端相关测试和生产构建通过；本次未修改后端。


空状态框选修复：仅当列表存在可用文件行时才允许开始拖动框选；没有 Diff、读取失败或树形目录全部折叠时均不显示选框。快照刷新会取消正在进行的框选，避免切换为空状态后留下选框。选择交互及 ReviewPanel 相关 76 项测试通过，包含新增的四种回归场景。
