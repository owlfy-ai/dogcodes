# 审查简化：Agent 自主读取代码与 Git 差异

日期：2026-09-27。此记录替代当前产品中的冻结审查、分组检索、强制独立 AI 二次复核要求；早期带日期记录保留为历史证据。

2026-09-28 更新：取消启动前的非 Git 会话基线，Diff 改用已记录的逐轮修改前内容与当前文件比较；不迁移或兼容旧会话基线。详见 [取消会话基线](remove-session-baseline-2026-09-28.md)。下文“保留非 Git 会话基线”是当时的实现状态，已被此决定替代。

## 当前行为

- 保留逐轮和 Diff 面板的代码审查、安全检查、性能分析图标、已有 Agent/额度菜单，不另造 UI。
- 项目入口只提供目录、比较模式、Git base/target、文件名和排除范围；不再读取或复制 Diff blob 组装完整代码材料。
- Agent 在实际项目目录自行调用读取、搜索、Git 工具。单次独立 Session/Run，额外项目目录同步传递；主 Agent、主 Run 和 SessionMap 不变。
- 未提交/未暂存/已暂存按对应 Git 语义重新获取；工作区可继续变化。历史提交仍是选定父提交→提交，首次提交从空树比较；分支比较使用面板解析后的对象，不改为当前工作区，也不二次计算 merge-base。
- 逐轮入口传该轮有界要求/回复摘录和文件线索，检查当前实现。历史快照缺失不再禁用入口；不会把当前代码称为那轮的历史版本。
- 非 Git 目录按变更文件线索读取当前代码；没有旧版本内容时明确不能还原精确历史差异。

## 删除与保留

删除宿主分组、JSON 上下文请求往返、独立二次复核执行器、冻结证据位置校验、固定安全专项覆盖矩阵及其专用测试。停止主轮次和 Diff 查询为 AI 预先收集未改动关联文件；移除相应采集模块。

保留结构化问题（路径、行号、严重程度、证据、建议）及 Markdown 回退。新位置为 Agent 自报，不显示虚假的历史 Diff 跳转/程序校验；选中问题→主 Agent 修复→独立复审当前代码继续可用。

新 review.started 只保存范围、线索和 hash；review.activity 批量保存实时展示项，review.updated 保存状态、结果和最终执行记录，不产生审查专用代码副本。旧报告、旧冻结来源读取和反序列化类型继续可读；不重放旧审查引擎，旧报告应从图标发起新审查。

**review/ 并非全部删除**：Diff 展示、非 Git 会话基线、文件/整轮撤销和恢复事务共用其原始内容。相应 blob、Artifact、漂移检查、回滚日志、引用计数与永久删除清理保留。此次没有清空用户既有数据，也未改变实际项目文件。

## 执行边界

- 2026-09-27 后续产品决定：审查授予完全权限，允许跨目录读取；只审查、不修改代码由提示词明确约束，不保证 OS 级只读隔离。
- Codex 使用 danger-full-access/never；Claude 使用 bypassPermissions；Grok 使用 always-approve；ZCode 使用 yolo；Kimi 使用原生语义校正后的 auto。其他安装按其上报的完全权限选择，不虚构权限 ID。
- 原生仍请求工具审批时，仅向该独立会话回答厂商提供的“本次允许”；不写入永久规则、不切换主对话权限。没有允许选项时明确失败。
- 界面删除 run.coverage 实现说明，来源仍在记录中保存。提示词强调多仓库通过显式 cwd/git -C 分别查询。
- 启动预算 1 分钟，实际审查预算 15 分钟，可独立取消；不再每组 3 分钟。重试新建 Session/Run，复用比较范围，工作区类重新读最新代码。
- 路径、Git 对象 ID 保持完整；消息、报告文字及证据正文继续脱敏。历史 Git 比较不会因高熵脱敏丢失对象 ID。
