# GitHub 说明页维护

## 命名约定

产品名称统一写为 `dog.codes`（同官网域名）；npm 包名、GitHub 仓库名、CLI 命令、`DOGCODES_` 环境变量、`@dogcodes/` 内部包作用域、设置存储键与协议标识仍使用 `dogcodes`。crate 目录、源码文件和文档文件按职责命名，不包含产品名；引用路径与 Cargo 命令使用实际目录和包名，例如 `crates/core`、`cargo test -p agent-core`。

软件尚未发布，命名调整直接更新代码、配置、环境变量、协议标识、设置存储键、实验记录和文档，不保留旧名称别名，也不添加旧名称兼容或数据迁移逻辑。环境变量使用 `DOGCODES_` 前缀，内部 npm 包使用 `@dogcodes/` 作用域，桌面应用标识为 `codes.dog.desktop`。

## 语言页面

默认页为根目录的 [README.md](../README.md)。其他语言放在 `docs/i18n/`，每页顶部均可切换到全部 9 个语言版本：英文、简体中文、繁体中文、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语。

修改功能范围时同步各语言版本。产品说明按已实现能力编写；灵动岛暂不列入发布功能。首页提供源码运行方式；安装包实际就绪后再更新下载入口和适用平台。首页不再标注开发预览、进度清单或手机端发布状态。

页面使用 GitHub 支持的 Markdown 和基础 HTML，不依赖自定义 CSS、JavaScript、外部徽章服务或固定仓库地址。

## 替换截图

2026-10-17 起各语言首页按最终卖点改为 1 张总览加 10 个功能截图位；2026-10-29 增加「用手机指挥 Agent」章节，新增手机端和远程桌面 2 个截图位（共 13 个）。截图暂由用户补充：页面里每个位置先以 HTML 注释留空（不渲染破图），注释写明建议文件名；放入 PNG 后，把对应注释替换为 `![标题](路径)` 即可，九个语言页面需同步。截图使用隔离演示数据，不作为真实供应商或原生三平台验收证据。`docs/images/readme/` 中旧的 7 张演示图暂保留，可复用或替换。

启动 `pnpm dev`，使用已安装的 Playwright 和 Chrome 执行：

```bash
node scripts/capture-readme.mjs
```

Playwright 不在项目运行依赖中；也可通过 `--playwright-module /absolute/path/to/playwright/index.mjs` 指定已有安装。`--base-url` 指定本机 Vite 地址，`--browser` 指定 Playwright Chromium channel，`--output` 可先输出到本机审阅目录。默认输出是正式文档图片目录，因此生成前应保留需要对比的旧截图。

生成器使用独立浏览器上下文、合成项目/会话、只读命令白名单及外部请求阻断，直接渲染 App、ReviewPanel、ProjectRunPanel 和终端等现有组件。它检查页面错误、业务错误提示和各场景关键元素后截图；完成后还需逐张检查可读性和遮挡。`readme-fixture.html` 仅供开发文档截图，不被生产入口导入，且拒绝在已有桌面连接的页面运行。

当前以 1600 × 1000 视口、1.5 倍像素密度输出 2400 × 1500 PNG，保持正文和代码可读。可按实际界面调整比例，页面会随图片自然缩放。

## 手机端说明

「用手机指挥 Agent」章节只写已实现的能力：配对与撤销、多台电脑、会话/审批/提问、Git、从 PC 目录添加项目、终端与运行、网页预览、文件与附件、远程桌面、推送通知；依据 `docs/implementation/mobile-*.md`、`remote-*.md` 及 `docs/CURRENT_WORK.md`。手机应用在独立仓库开发；页面不写其发布状态、商店或下载入口，上架后再补。本地优先的表述为「代码、对话与凭据留在电脑上；可选的手机连接端到端加密，中继只转发密文」，不再写「完全不经过中继」。桌面界面语言为 11 种（含俄语、意大利语）；README 页面本身仍为 9 种语言。
