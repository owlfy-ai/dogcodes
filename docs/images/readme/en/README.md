# English README feature illustrations

19 PNGs drawn with the built-in image_gen tool, based on the desktop and phone UI. These are editorial feature illustrations, not direct screenshots or runtime acceptance evidence. Conversations, code, quotas and account readings are curated fictional examples around the Ledger invoice development workflow.

- Open `preview.html` to review the complete set.
- Each applicable image presents the desktop first (upper-left), followed by the phone (lower-right). The desktop language chooser is desktop-only.
- Root `README.md` references this English set. Other language READMEs and the existing shared screenshots are preserved pending acceptance.
- `prompts.json` records the prompt set and corrections. `manifest.json` records source files and topics.

Only existing capabilities are illustrated. Computer agent setup and updates remain desktop operations; phone views use the paired computer. The computer must remain online with dog.codes open or minimized.
