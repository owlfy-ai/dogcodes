# English README feature illustrations

20 PNGs drawn with the built-in image_gen tool, based on the desktop and phone UI. These are editorial feature illustrations, not direct screenshots or runtime acceptance evidence. Conversations, code, quotas and account readings are curated fictional examples around the Ledger invoice development workflow.

- Open `preview.html` to review the complete set.
- Features illustrations show only the desktop. The Remote hosts section includes two views: agent installation/quota/version management, and server-folder selection with a remote Cursor conversation.
- The overview and phone-remote illustrations retain the desktop first (upper-left), followed by the phone (lower-right). The phone chapter uses the preserved `switch-agent-phone.png`, `git-changes-phone.png`, and `run-project-phone.png` variants.
- All nine language READMEs share this English illustration set. The three removed feature sections are also removed from every translated README.
- `prompts.json` records the prompt set and corrections. `manifest.json` records source files and topics.

Only existing capabilities are illustrated. Computer agent setup and updates remain desktop operations; phone views use the paired computer. The computer must remain online with dog.codes open or minimized.

The Computer Use illustration follows the current global settings toggle and conversation activity rows. It shows Cursor verifying a local Ledger web app. It does not represent a measured comparison with Codex.

The remote-host images follow `ExecutionTargets.tsx`, `HostAgentManagement.tsx`, `QuotaPanel.tsx` and the actual server directory picker. Build server, its folders, account readings and development results are fictional showcase content. No personal host addresses or test chats from the source screenshot are distributed.
