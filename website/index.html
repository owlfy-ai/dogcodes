    seamless handoff

    Switch agents. Keep the conversation.

    Change the agent running a conversation at any moment. dog.codes hands over the context automatically — no copy-paste, no re-explaining.

    • Give each task to the agent best suited for it — one designs, another fills in the details.
    • Out of quota? Another agent picks up the work without restating the requirements.
    • The new agent can look up earlier turns through built-in history tools. It truly continues.

    Your computer stays on and your agents keep running. From your phone you can pick up conversations, approve actions, ship code — and take over the whole screen when you must.

    The phone app is coming soon. Keep dog.codes open on your computer; minimizing is fine.

    Scan once. Stay private.

    Pairing is a one-time QR scan, then the link is end-to-end encrypted. Pair several computers, see which are online, and revoke a phone any time.

    Same sessions, same agents.

    The phone is a window onto the sessions already running on your computer — history, forks and quotas included. Your code and your agents stay on your computer.

    Approvals stay yours.

    Agents still ask before they act. Every request is checked against the original run on your computer before your approval is applied.

    quota & usage

    Every quota, every reset. One glance.

    Remaining quota, reset times and versions for your agents in one place, wherever the agent reports them. Plan your work around them and make every token count — then upgrade any agent in one click.

    Use the plans you already have

    dog.codes drives the official CLIs you're signed in to — Claude Code, Codex, Cursor and more. No separate account, no extra API bill.

    Found automatically

    Installed agents and their sign-in status are detected on launch, with official install links for the rest.

    Local-first by design

    Your code and data stay on machines you control. The optional phone link is end-to-end encrypted. Agents start with only the environment they need, so your other secrets stay yours.

    cross-agent review

    Let one agent review another.

    Ask a different agent — a different model — to review what was just changed. Fresh context, no shared blind spots. Security and performance passes included.

    • Findings ranked high, medium and low.
    • Pick what matters, then start the fix in one click.
    • The fix goes back to the main agent with the report attached — context stays intact.

    computer use

    Every agent can use your computer.

    Give agents that can't operate a computer, or check their own work, Codex-level computer use. They look at the screen, open apps, and click, type and scroll in real interfaces.

    Sees the screen. Uses real apps.

    The agent reads what is on screen, then clicks, types and scrolls in the apps you actually run. Each action appears in the conversation with a live screenshot.

    Closes the loop.

    Run the project, reproduce the problem in the UI, fix the code, then go back to the app and check the result, all in one conversation.

    You stay in control.

    One switch turns it on or off for every agent. Press Esc to stop the action in progress.

    Needs a compatible agent and your system's permissions. Not available for Pi. On a Mac, needs macOS 13 or later.

    fork across agents

    Branch the idea. Race the agents.

    Fork a new conversation from any turn and hand it to a different agent. The original stays untouched; in Git projects, worktrees keep each approach's code isolated.

    • Let several agents attempt the same task.
    • Compare the results side by side, keep the best.

    remote hosts

    Your servers. Your agents. One workspace.

    Connect to a server over SSH and work there as if it were local. Install agents on the host in one click, open its folders as projects and assign tasks — the code never leaves the server.

    gpu-box

    Plain SSH. Nothing to set up.

    Pick a host from your SSH config and connect with the keys you already use, through a proxy if you need one. A small helper lives in your home directory: no root, no system service.

    The code stays on the server.

    Nothing is copied to your computer. Files, Git changes, code review, terminals and project run commands all work on the host, from the same desktop.

    The conversations you know.

    Agents on the host stream their replies and ask for permission and answers in the same conversation view. Remote and local projects sit side by side, grouped by machine.
